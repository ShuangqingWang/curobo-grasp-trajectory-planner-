# 轨迹规划逻辑分析 — 末端碰撞球方案

> 本文只定义**末端夹爪**的碰撞球排布。机械臂本体（7 个连杆）的碰撞球不在本文范围内。
>
> 前置依赖：《轨迹规划逻辑分析_碰撞空间范围方案.md》，该文定义 ESDF 长方体范围与建立算法；
> 本文定义末端如何布置碰撞球去查询那张距离场。
>
> 单位：长度 mm。坐标均为**末端挂载坐标系**（原点在法兰面，见第 1 节）。

---

## 1. 末端几何

末端按轴对齐长方体建模，六个方向的延伸量来自 `config/base/app.json` → `end_effector`：

| 轴 | 负方向延伸 | 正方向延伸 | 总尺寸 | 含义 |
| --- | ---: | ---: | ---: | --- |
| X | 31 | 31 | 62 | 夹爪宽度方向 |
| Y | 50 | 50 | 100 | 夹爪厚度方向 |
| Z | 0 | 200 | 200 | 沿工具轴，Z=0 是法兰面，Z=200 是夹爪尖端 |

即长方体角点范围：X ∈ [−31, 31]，Y ∈ [−50, 50]，Z ∈ [0, 200]。

**Z = 0 面是法兰安装面（近法兰）；Z = 200 面是夹爪尖端（远端）。**

---

## 2. 排布规则

### 2.1 只在棱线上放球，不填面、不填内部

长方体有 12 条棱，按方向分三类，每类 4 条：

| 棱方向 | 棱长 | 位置（另两轴取端值） | 条数 |
| --- | ---: | --- | ---: |
| 平行 X | 62 | y ∈ {−50, 50}，z ∈ {0, 200} | 4 |
| 平行 Y | 100 | x ∈ {−31, 31}，z ∈ {0, 200} | 4 |
| 平行 Z | 200 | x ∈ {−31, 31}，y ∈ {−50, 50} | 4 |

球心**直接落在棱线上**，不内缩、不外扩定位——即球心到长方体表面的名义距离为 0。

### 2.2 近法兰的 4 条棱只留角点，不放中间球

Z = 0 面（近法兰）的 4 条棱——2 条平行 X（y=∓50, z=0）、2 条平行 Y（x=∓31, z=0）——
**中间不放球，只保留两端角点**。角点本身由平行 Z 的 4 条竖棱提供（见 2.3），不需要额外补点。

依据：末端在抓取作业中，实际接触障碍的部位集中在夹爪尖端（Z=200 附近）及连接两端的竖棱；
近法兰这一侧被腕部结构遮挡，不会单独暴露给障碍物。

### 2.3 实际放球的 8 条棱

| 棱 | 条数 | 说明 |
| --- | ---: | --- |
| 平行 Z（4 条竖棱，连接 Z=0 与 Z=200） | 4 | 贯穿全长，两端即长方体的 8 个角点 |
| 平行 X，Z=200（尖端侧） | 2 | |
| 平行 Y，Z=200（尖端侧） | 2 | |

其余 4 条棱（Z=0 侧的平行 X、平行 Y）**不放中间球**。

### 2.4 球的半径与阈值

| 参数 | 值 |
| --- | ---: |
| 碰撞球半径 | **3 mm** |
| 激活距离（阈值） | **3 mm** |

## 3. 单条棱要放几个球——覆盖无缝的推导

一条棱是条线段，两端各放一个球心（覆盖角点），中间按固定间距均匀排。
要保证棱上任意一点到最近球心的距离 ≤ 半径，相邻球心间距不能超过 **2 × 半径 = 6 mm**：

```text
n ≥ 棱长 / (2 × 半径) + 1
```

| 棱长 | n ≥ | 取整 n | 实际间距 | 实际半间距 | 是否覆盖（半间距 ≤ 3mm） |
| ---: | ---: | ---: | ---: | ---: | --- |
| 62 mm | 11.33 | **12** | 62/11 = 5.636 mm | 2.818 mm | ✅ |
| 100 mm | 16.67 | **18** | 100/17 = 5.882 mm | 2.941 mm | ✅ |
| 200 mm | 33.33 | **35** | 200/34 = 5.882 mm | 2.941 mm | ✅ |

少一个球都不行：例如 62mm 棱若只用 11 个球，间距变成 6.2mm、半间距 3.1mm，超出半径 3mm，会漏检。

## 4. 球数汇总

### 4.1 逐类计算

**平行 Z 的 4 条竖棱**——全部放满，贯穿 Z=0 到 Z=200，两端即长方体全部 8 个角点：

```text
4 条 × 35 个/条 = 140 个（含 8 个角点 + 132 个中间点）
```

**平行 X 的 2 条棱（Z=200 侧）**——两端角点已被竖棱计入，只数中间新增的：

```text
2 条 × (12 − 2) 个/条 = 20 个
```

**平行 Y 的 2 条棱（Z=200 侧）**——同理：

```text
2 条 × (18 − 2) 个/条 = 32 个
```

**平行 X、平行 Y 的近法兰 4 条棱**——中间不放球，端点已被竖棱计入，新增 **0 个**。

### 4.2 合计

```text
140 + 20 + 32 + 0 = 192
```

**末端碰撞球总数：192 个。**

全部半径 3mm；分布在 8 条棱上（4 条竖棱 + 尖端侧 2 条 X 向 + 2 条 Y 向），
外加这 8 条棱天然共享的全部 8 个角点。

## 5. 精确球心坐标（末端挂载坐标系）

### 5.1 平行 Z 的 4 条竖棱（各 35 个球）

```text
x ∈ {−31, 31}，y ∈ {−50, 50}（4 种组合）
z_k = k × (200 / 34)，k = 0, 1, …, 34   （35 个值，从 0 到 200）
```

### 5.2 平行 X 的 2 条棱，Z=200（各 10 个中间球，端点已在 5.1 中给出）

```text
y ∈ {−50, 50}，z = 200
x_k = −31 + k × (62 / 11)，k = 1, …, 10   （10 个值，不含 k=0 和 k=11）
```

### 5.3 平行 Y 的 2 条棱，Z=200（各 16 个中间球，端点已在 5.1 中给出）

```text
x ∈ {−31, 31}，z = 200
y_k = −50 + k × (100 / 17)，k = 1, …, 16   （16 个值，不含 k=0 和 k=17）
```

## 6. 安全余量核算

沿用本项目统一公式：

```text
净余量 = 碰撞球外凸 + 激活距离 − 球覆盖间隙 − 体素量化误差
```

| 项 | 值 | 说明 |
| --- | ---: | --- |
| 碰撞球外凸 | **3 mm** | 球心内缩 = 0（直接落在棱线/表面上），外凸 = 半径 − 内缩 = 3 − 0 |
| 激活距离 | **3 mm** | 本方案阈值 |
| 球覆盖间隙 | **0**（8 条放球的棱范围内） | 由第 3 节的 ≤2r 间距规则保证 |
| 体素量化误差 | **依赖 ESDF 体素尺寸** | 见 6.1 |

### 6.1 体素尺寸依赖

本方案的余量预算按体素 **3 mm** 计算：

```text
体素量化误差硬上界 = 体素边长 × √3 / 2 = 3 × 1.732 / 2 = 2.598 mm
```

```text
净余量 = 3 + 3 − 0 − 2.598 = 3.402 mm
```

**该数字依赖 ESDF 最终采用的体素尺寸。** 体素尺寸由《碰撞空间范围方案》一并确定，
若最终体素大于 3mm，净余量会相应减小，需回到此表重算。

### 6.2 与本体连杆球的余量对比（仅列出，不在本文范围内核算本体）

本体连杆球覆盖率 0.74～0.90、最大缝隙 7～17mm 的问题不在本文讨论范围，
其余量核算见本体专项文档。

## 7. 与原方案对比

| | 原方案（球心内缩） | 本方案（棱线布球） |
| --- | ---: | ---: |
| 球数 | 96 | **192** |
| 排布方式 | 内部网格，球心内缩 12.5mm | 只在 8 条棱上，球心不内缩 |
| 半径 | 21.65 mm | **3 mm** |
| 外凸 | 9.15 mm | **3 mm** |
| 激活距离 | 5 mm | **3 mm** |
| **有效膨胀（外凸+激活距离）** | **14.15 mm** | **6 mm** |
| 覆盖方式 | 盒体内部完全覆盖（含面、含体） | 仅 8 条棱覆盖，近法兰 4 条棱中段无覆盖 |

有效膨胀从 14.15mm 降到 6mm，降幅 **57.6%**。球数从 96 增至 192（约 2 倍），
两段 trajopt 按边际 8.84 ms/球估算，末端部分预计增加约 850 ms，需实测复核。

---

## 8. 已知限制

**近法兰 4 条棱的中段没有碰撞球保护**，仅两端角点被覆盖。这是基于业务判断——
该区域在实际抓取中被腕部结构遮挡、不会单独暴露给障碍物——而非几何覆盖完整。
若后续场景出现近法兰区域独立接触障碍的情况，需要重新评估此假设。

## 9. 待确认事项

1. **体素尺寸**：本文余量核算按 3mm 体素预设，最终数值以《碰撞空间范围方案》为准。
2. **球数增加对耗时的实际影响**：第 7 节的 ~850ms 估算为按边际系数推算，需要离线实测复核。
3. **PBA 单轴 1024 格上限**与体素尺寸的联动关系由范围方案负责，不在本文处理。
